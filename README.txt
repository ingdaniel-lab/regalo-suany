# Regalo para Suany ❤️

Página de cumpleaños de Daniel para Suany.

## Estructura
- `index.html` — página principal
- `styles.css` — diseño y animaciones
- `script.js` — interacciones
- `assets/` — las 5 fotos que subiste

## Publicarla gratis con GitHub Pages
1. Crea una cuenta en GitHub si todavía no tienes una.
2. Crea un repositorio nuevo, por ejemplo `regalo-suany`.
3. Sube TODO el contenido de esta carpeta (no subas la carpeta contenedora, sino sus archivos).
4. En el repositorio entra en **Settings → Pages**.
5. En "Build and deployment" selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`.
7. Guarda y espera a que GitHub te entregue la dirección de tu página.
8. Ese enlace será el que convertiremos en un QR.

## Música
El botón "Escuchar" abre el video oficial de "Caminar de Tu Mano" de Río Roma en YouTube. No se incluye el archivo de audio dentro de la página.

## Personalización rápida
Puedes cambiar textos directamente en `index.html`. Las fotos están en `assets/`.
